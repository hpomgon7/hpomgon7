## 🧠 / Cómo afronto un proyecto

Cuando tengo un problema delante, intento no empezar a programar directamente sin saber hacia dónde voy. Normalmente en mi mente sigo unos pasos algo parecido a esto:

1. **Entiendo el problema** para tener claro lo que quiero conseguir.
2. Pienso una **estructura inicial** y divido el problema en partes más pequeñas.
3. Desarrollo una primera versión de lo que tenía en mente que cumpla la función esperada.
4. Reviso que partes puedo hacer de una forma más sencilla.
5. Pulir el resultado final, sobretodo si es una interfaz web, aunque me gusta que sea lo que sea, si se puede interactuar con ello, sea bonito de ver.

Me gusta especialmente ese proceso de ir pasando de una idea inicial a algo cada vez más completo y mejor organizado.

## 🐍 / Un poco de código

Python es el lenguaje con el que más he trabajado hasta ahora. Un ejemplo de código simple de una de las tareas que tuve que hacer el año pasado es el siguiente:

```python
class Rectangulo:
    def __init__(self, ancho: float, alto: float):
        self.ancho = ancho
        self.alto = alto
    def area(self) -> float:
        return self.ancho * self.alto
    def perimetro(self) -> float:
        return (self.ancho*2)+(self.alto*2)

#Uso:
rectangulo = Rectangulo(5,3)
print("Area:",rectangulo.area())
print("Perimetro:",rectangulo.perimetro())
```

Este ejemplo específicamente es de cuando empezamos a aprender sobre las clases.
